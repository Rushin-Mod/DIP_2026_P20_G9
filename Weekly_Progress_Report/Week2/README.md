# Week 2 – Basic Hands-On and Method Exploring

This folder contains the **Week 2 work** for the Brain MRI Tumor Segmentation and Quantitative Analysis project.

## Work Completed

- Explored brain MRI scans from the OpenNeuro dataset.
- Studied potential tumor regions and their visual characteristics.
- Developed a Python approach for opening `.nii.gz` MRI files.
- Explored MRI visualization using **MRIcroGL**.
- Performed initial manual observations of tumor boundaries.
- Reviewed research on **frequency-domain methods** for brain tumor segmentation.
- Studied an annotated brain tumor dataset for understanding segmentation and ground-truth annotations.

## Upcoming Work

- MRI preprocessing and image analysis.
- Spatial and frequency-domain transformations.
- Convolution and filtering techniques.
- Tumor localization and segmentation.
- Quantitative analysis of tumor characteristics.
